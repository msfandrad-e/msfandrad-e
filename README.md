## 📊 Projetos em destaque

### Dashboard de Controle de Contratos

Aplicação desenvolvida em Python e Streamlit para importação, tratamento, análise e visualização de dados contratuais.

**Funcionalidades:**
- Importação de arquivos Excel e CSV.
- Tratamento e manipulação de dados com Pandas.
- Indicadores e métricas de acompanhamento.
- Gráficos interativos com Plotly.
- Filtros para exploração dos dados.
- Exportação de informações em diferentes formatos.
